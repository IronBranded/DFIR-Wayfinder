# Sources & Attribution

This academy is original writing built from the facts, structures, and taxonomies published by the following, carried forward from the original Enterprise DFIR Field Guide this academy is built on:

- **SANS** — course material and posters (FOR500, FOR508, FOR572, and the certification program generally)
- **Microsoft** — Microsoft Learn documentation, Microsoft Internals research, Microsoft Cloud/Entra documentation, and MSTIC (Microsoft Threat Intelligence Center) publications
- **13cubed** (Richard Davis) — NTFS timestamp and Prefetch research specifically cited in Level 2
- **MITRE ATT&CK** — the technique taxonomy used throughout

Nothing is reproduced verbatim from any source; each lesson links out to primaries for readers who want the original material. Scope note carried from the source guide: this academy is built for enterprise DFIR — SOC analysts, incident responders, and threat hunters — not for criminal-prosecution workflows.

## A note on how this academy was built

The lesson/level structure and interactive engine (progress tracking, quizzes, search) are adapted from IronBranded's own [Malware Analysis Academy](https://ironbranded.github.io/Malware-Analysis-Academy/), reused with a new visual identity and re-themed for DFIR content specifically. The underlying content is carried forward and restructured from the [Enterprise DFIR Field Guide](https://github.com/IronBranded/Microsoft-DFIR-Wayfinder) — the same 111-page knowledge base, re-authored lesson by lesson into this format.
